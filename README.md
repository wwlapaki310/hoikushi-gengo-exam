# 保育士試験 言語に関する技術 対策リポジトリ

## 概要

このリポジトリは、保育士試験の「言語に関する技術」実技試験対策用の台本集です。
3歳児クラスの子どもたちに向けた3分間のお話を3つ収録しています。

## 試験要項

### 課題内容
以下の3つのお話から、当日1つが指定されます。

1. **ももたろう**（日本の昔話）
2. **おむすびころりん**（日本の昔話）
3. **3びきのこぶた**（イギリスの昔話）

### 試験条件
- **対象**: 3歳児クラス（15人程度を想定）
- **時間**: 3分間
- **スタイル**: 絵本・道具・台本等の使用禁止
- **身振り手振り**: 適切に加える
- **姿勢**: 立っても座ってもOK

### 評価ポイント
- 基本的な声の出し方
- 表現上の技術
- 幼児に対する話し方

## 各お話について

### [ももたろう](./ももたろう/script.md)
桃から生まれた男の子が、犬・猿・雉を仲間にして鬼退治に行くお話。
3歳児が理解しやすいよう、キャラクターの特徴を際立たせています。

### [おむすびころりん](./おむすびころりん/script.md)
おむすびを追いかけて穴に落ちたおじいさんが、ねずみの国で楽しい体験をするお話。
繰り返しの表現とリズムで子どもたちを引き込みます。

### [3びきのこぶた](./3びきのこぶた/script.md)
3匹の子ぶたが、それぞれの家を建て、オオカミから身を守るお話。
「ふー、ふー」の息遣いで子どもたちと一体感を作ります。

## 準備のポイント

### 1. 声の出し方
- **明瞭に**: 子どもたちの耳に届くよう、はっきりと
- **抑揚をつけて**: キャラクターごとに声色を変える
- **適切な音量**: 15人に届く声量で、叫ばない
- **テンポ**: 3歳児が理解できる速さで

### 2. 身振り手振り
- **大きく**: 後ろの子にも見えるように
- **シンプルに**: 複雑すぎない動き
- **お話に合わせて**: 場面を想像させる動き
- **自然に**: 不自然にならない程度に

### 3. 表情
- **豊かに**: 喜怒哀楽を表現
- **子どもたちを見る**: 目線を全体に配る
- **笑顔**: 基本は優しい笑顔で

### 4. 時間管理
- **3分厳守**: 各台本は約3分を想定
- **練習で確認**: タイマーを使って何度も練習
- **調整方法**: 長い場合は間を詰める、短い場合は間を取る

## 練習方法

### ステップ1: 台本の理解
各台本をよく読み、お話の流れを理解する

### ステップ2: 音読練習
声に出して読み、言いにくい箇所を確認する

### ステップ3: 身振り手振りを加える
動きを考え、台本に書き込む

### ステップ4: タイマーで計測
3分ピッタリになるよう調整

### ステップ5: 録画チェック
スマホで録画し、自分の姿を客観的に確認

### ステップ6: 人前で練習
家族や友人に聞いてもらい、フィードバックをもらう

## よくある注意点

❌ **やってはいけないこと**
- 絵本を持つ
- 台本を見る
- 人形などの道具を使う
- 子ども扱いしすぎる（赤ちゃん言葉など）
- 早口すぎる、遅すぎる
- 棒読み

✅ **心がけること**
- 子どもたちの目を見る
- ワクワク感を伝える
- 一緒に楽しむ気持ち
- 安心感のある声
- お話の世界に引き込む

## 当日の心構え

1. **深呼吸**: 入室前に落ち着く
2. **笑顔**: 子ども(椅子)に挨拶
3. **楽しむ**: 自分が楽しむことが大切
4. **3分間**: 途中でも退出できないので最後まで
5. **自信を持って**: 練習した成果を発揮
